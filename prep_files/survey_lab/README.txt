The Prep files are structured in the following way:
1. Sheets with color BLUE contain "Raw" data given by the RMI team, not modified.
2. All modifications are done in the GREEN sheets, so these are the ones that serve as input for the validation script.

The validation script then outputs processed files that are the ones that can be found in the "exports" folder.

Except for 2021, in Investment Intentions we were not given the Raw data in the form of an Excel file. The Raw data is not stored in the Prep files, and these only contained the final processed data.
